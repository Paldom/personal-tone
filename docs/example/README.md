# Example: what the pipeline produces

Everything here was generated by `make_example.py` from a **synthetic** mailbox (a made-up
"Alex Example" writing to made-up clients and colleagues). No real correspondence, no real
people. Re-run it after changing the scripts: `python3 docs/example/make_example.py`.

| File | Produced by | What to look at |
| --- | --- | --- |
| `home/corpus.jsonl` | voice-corpus | one JSON line per message Alex wrote: register, date, `is_reply`, redacted `text` (`[name]`), flags |
| `home/corpus-report.md` | voice-corpus | samples and words per register, coverage tier, drop reasons, redaction counts |
| `home/metrics.json` | voice-profile | every aggregate feature, per-message p10/p50/p90 bands, openers, n-grams |
| `home/profile.json` | voice-profile | the canonical profile the other skills read: bands, opener/sign-off classes, never-candidates, `bans`, `keep` |
| `home/exemplars.json` | voice-profile | 5 sample ids per register, stratified by length (text stays in the corpus) |
| `home/profile.md` | voice-profile (the model) | the human-readable narrative written from the numbers |
| `profile-summary.txt` | voice-profile | the summary the script prints |
| `pick-exemplars.txt` | voice-write | the DATA block the writer gets: length budget, skeleton, five samples |
| `voice-check.md` | voice-check | a generic assistant draft (FAIL: 63 words vs p90 28, four AI-default phrases, politeness markers) versus a genuine one (INCONCLUSIVE: 16 words), plus the leave-one-out self-test |
| `home/calibration.jsonl` + `delta.txt` | voice-calibrate | the logged draft-vs-sent pair with tags `LENGTH_CUT`, `LESS_FORMAL`, `LLM_ISM`, `SIGNOFF` |

In real use the home directory is `~/.personal-tone/`, mode 0700, with a `.gitignore` of `*`;
it is committed here only because the data is fake.
